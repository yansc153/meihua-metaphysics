# 玄学板块 PRD

状态：v1 范围。canonical 产品是花椒短线。起卦不在 Rust 里。

## 用户看到什么

两个页面，都在订阅闸门后面。

**美股日频。** 一张标普指数卡，加一组板块格（含商品 ETF），加一组 AI 分组格。每格显示本卦名、互卦名、起势档位和断语、收势档位和断语、旺衰一句、变盘标记。互卦不加第三档。收势只展示这一场的后段。指数卡用时间卦：农历取该美股交易日的公历日期，时辰固定巳时，数是 6。休市日改到下一场实际开盘再起卦。板块和 AI 分组只用目标日之前上一场的不复权开盘、收盘印价，各位数字相加，不预舍入。开盘或收盘缺失、为零或不是有限数，则该格为「缺价」，不借用邻格的卦。旺衰只看目标交易日的节气月建，标体当令、体失令或体中，不改档位。

**问事。** 三个字段：代码、事项（短文本）、起卦时间。默认时间是提交时刻。农历年月日和时辰都取这个时刻在 Asia/Shanghai 的钟面，不用该分钟的价格，也不套用日频的巳时。代码必须在美股允许列表里；A 股代码在网关就拒绝。每个登录用户每个 Asia/Shanghai 自然日最多 3 次成功起卦。午夜 0 点计数归零。第 4 次请求得到配额用尽，不返回新卦。

A 股页面不增加玄学板块格。用户停在 A 股导航时，看不到上证、深成指、创业板、科创板或任何 `g=cn` 代码的卦。

## 闸门

| 情况 | 页面 |
|---|---|
| 未登录 | 锁。不显示卦 |
| 已登录、订阅无效或过期 | 锁。不显示卦 |
| 已订阅、Python 服务不可用 | unavailable。不显示卦 |
| 已订阅、某个板块没有上一场开收盘，或价格为零、非有限数 | 该格「缺价」。其他有价的格仍显示 |
| 问事字段为空，或代码不在美股允许列表，或是 A 股 | 校验失败，不计数，不调用起卦服务 |
| 当日成功次数已达 3 | 配额用尽，不调用起卦服务 |

不允许用占位卦、昨日的卦冒充今日、或由前端自己起卦。

## v1 不做

盘中改卦。把成交量、最高价、最低价送进数字和。周卦。命中率屏。变体 B。A 股板块板。把齐济 64×64 的操作文句和体用五句合成一句。

## 断语

体用五句只用总诀的话：用生体，有进益；体克用，事情可成；体用比和，顺；体生用，有耗泄；用克体，事情不利。对应档位：偏多、略偏多、震荡、略偏空、偏空。

动变只描述这一场：用吉而变成凶，先吉后凶；用凶而变成吉，先凶后吉。吉侧是「有进益」和「事情可成」。凶侧是「有耗泄」和「事情不利」。「顺」不算偏空侧。

## 验收

- 同一交易日，页面上的标普卦与 Python `cast_index` 相同。
- 板块格的数字和与「印价每一位相加、不预舍入」相同。`763.3` 与 `763.30` 同和。
- A 股代码在日频响应里出现则为失败。
- 停掉 Python 进程后，日频接口仍是 HTTP 200，信封为 unavailable，响应体里没有卦名。`/api/us/metaphysics/` 不进前端 API 缓存。
- 同一用户在上海时区连续成功问事 3 次后，第 4 次不再到达 Python。失败和超时回滚占位，不计数。跨过上海午夜后第 1 次再次到达 Python。
