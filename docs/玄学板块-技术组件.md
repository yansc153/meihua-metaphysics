# 玄学板块技术组件

状态：合并计划。起卦服务用 Python。花椒的 Rust 只做闸门和转发。

## 为什么是 Python 服务

现有起卦、农历、节气和回测已经在 `预测易经/engine` 里，用的是 Python 3。体用规则若再写进 Rust，会有两套 `cast`。约束是 Rust 里不放占卜逻辑，所以 Axum 不导入这些函数，只发 HTTP。

服务名 `meihua`。监听 compose 网络内的 8090，不映射到宿主机公网端口。环境变量 `MEIHUA_URL=http://meihua:8090`，只配在 backend 容器。

## 接口

`POST /v1/cast/daily`

请求：`session`（美股交易日）、`index`（固定标普，时辰巳时）、`prints`（代码到上一场开盘字符串、收盘字符串）。  
响应：每个代码一条记录，字段与 `engine/cast.py` 的日频结果相同，外加 `reversal`（变盘标记）。缺价记录的 `status` 为 `missing`。

`POST /v1/cast/question`

请求：`symbol`、`asked_at`（带时区的时刻）、`note`（不参与公式，只回显）。  
响应：一张时间卦。农历和时辰都取 `asked_at` 在 Asia/Shanghai 的年月日和时辰。这不是盘中价格改卦，也不是日频的巳时。

两个接口都没有用户 id。配额和订阅由 Axum 在调用前做完。

## 查表 JSON

规则表 `knowledge_base/meihua_64x6.json`：键是本卦加一个动爻，共 384 格。格内是体、用、五行关系、总诀断语、变卦、收势。时间卦的年月日式子不要求落进这 384 格的每一种。上屏断语与 `engine/cast.py` 一致：用生体，有进益；体克用，事情可成；体用比和，顺；体生用，有耗泄；用克体，事情不利。

齐济文句表 `knowledge_base/qiji_64x64.json`：本卦到变卦。只有从 1996 年书里摘出的句子才写入。摘不到的键不出现。服务读到缺失键时不编造操作建议，日频页面也不显示齐济文句。

旺衰不写进每一格。它由体的五行和目标日的节气月建在运行时算。

## Axum

新路由放进 `backend/src/api/mod.rs` 的 `router()`，因此自动经过 `subscription_gate`：

- `GET /api/us/metaphysics/daily`
- `POST /api/us/metaphysics/question`

Axum 组装请求，不把浏览器的查询原样转去。它只检查 Python 的 HTTP 状态和 JSON 形状，不解释五行。Python 5xx、连接失败、超时（3 秒）时，Axum 回 HTTP 200 和现有 `status: unavailable` 信封，正文没有卦名。日频是 GET，必须把 `/api/us/metaphysics/` 排除出 `frontend/public/sw.js` 的 API 缓存，否则停掉 Python 后仍会先吐出上一份带卦名的响应。

问事 POST 写在 `api::router()` 里，和日频一起过 `subscription_gate`。不要在 `main.rs` 里按 ML webhook 那样另挂到闸门外。

页面 id 用 `us-meihua-daily` 和 `us-meihua-question`。除了 `US_CONTEXT_NAV`，还要登记 `frontend/src/main.jsx` 的视图分支和标题。`A_CONTEXT_NAV` 不加项。

问事配额表是 `0059`：

`metaphysics_question_quota (email, day_shanghai date, used int, primary key (email, day_shanghai))`

网关用登录邮箱锁住当日行。`used` 未满 3 才占位并调用 Python。返回的 JSON 是一张完整时间卦才提交占位。失败、超时或非法 JSON 回滚占位。空字段和不在美股允许列表中的代码（含 A 股）在占位前拒绝。

v1 不建印价表。板块开收盘由 Python 读日线 CSV 里上一场的不复权字符串。以后若采集入库，用 `0060`，列只有交易日、代码和两段印价文本。

## React

`frontend/src/navigation.js` 的 `US_CONTEXT_NAV` 增加「日频」和「问事」。组件放在 `frontend/src/views/us/`。A 股的 `A_CONTEXT_NAV` 不增加入口。

客户端不实现 `mod 8`。日频响应里的 `missing` 渲染成缺价。顶层 `unavailable` 渲染成不可用。401 和 403 走现有的锁。

## 部署

`deploy/docker-compose.yml` 增加 `meihua`，构建上下文是起卦服务目录，`restart: unless-stopped`，无 `ports` 主机映射。backend 的 `depends_on` 加上它。健康检查只访问 `GET /v1/health`，该路径返回服务名和规则版本，不返回卦。

Mac mini 上的 launchd 继续只拉起名为 `deploy` 的 compose。不给 `meihua` 单独的公网隧道。
