# 梅花日频预测引擎设计

状态：设计稿。范围只做美股。档位数量、失令变体、美股开盘时辰三条已确认，见第 7 节。本文不包含实现。

读者：花椒短线作战平台的玄学板块，以及本仓库 `dashboard/`。A 股不在本引擎内。

依据：`knowledge_base/notes/梅花易数_宋代藏本_起卦.md`、`梅花体用总诀.md`。体用取静卦为体、动卦为用，断语用总诀五句。不采用《梅花易数实战方法》的「动为体」，不把填爻、六爻妻财、四柱月令写进同一次起卦。

## 1. 引擎要回答的问题

对一个已确定的交易日会话，在开盘之前给出一句总诀断语，并给出一个语言档位。档位描述这场会话的倾向，不描述涨停、跌停或目标价。

两个时间尺度，分开起卦，不从同一组价格拆出五天五个卦。指数只走第 3.2 节的时间卦，不走数字和，也没有周数字和。周尺度只覆盖板块和个股。

| 尺度 | 问题 | 何时能算 | 用哪次行情 |
|---|---|---|---|
| 下一交易日，指数 | 下一个开盘到收盘这场怎么走 | 下一场开盘之前 | 目标日的农历与巳时，见 3.2 |
| 下一交易日，板块与个股 | 下一个开盘到收盘这场怎么走 | 上一场收盘之后、下一场开盘之前 | 上一场的开盘价、收盘价 |
| 下一周，板块与个股 | 下一个整周怎么走 | 本周最后一场收盘之后 | 本周开盘价、本周最后一场收盘价 |

「随后几个交易日」不另起卦。日卦里的先与后只指这一场的前段和后段：本卦体用是起势，变卦之后的体用是收势。主命中只用起势，对照这场开盘到收盘。收势只展示。互卦只显示卦名，不另出一档。

## 2. 和论文方法的对应

《Incorporating I Ching Knowledge Into Prediction Task via Data Mining》（Liu 等，2023）把特征压成六爻，再把卦辞分成下跌、平稳、上涨，预测的是下一季度到下一年。本引擎只借用三件事：规则在看见结果之前冻住；输出是档位而不是价格；用一段历史日线做对照。

不借用的部分：随机森林筛特征、三才八种顺序按标签挑选、滑动窗口把数值切成老阴少阴、64 卦辞人工分类表、季度样本。那些步骤会把断语改成对着历史拟合的分类器。本引擎的断语表来自总诀，不随回测改写。

## 3. 起卦层

两套起卦，一套断卦。指数只用 3.2 的时间卦。美股板块和个股只用开盘价和收盘价的数字和。高低价、成交量显示在侧栏，不进入公式。标普与纳指在同一农历日、同一巳时卦相同；回测分母只留标普，见 5.1。

### 3.1 公共函数

先天数：1 乾、2 兑、3 离、4 震、5 巽、6 坎、7 艮、8 坤。

```text
mod8(n) = n mod 8；余数 0 取 8
mod6(n) = n mod 6；余数 0 取 6
```

上卦三爻在上，下卦三爻在下。第 `moving` 爻自下而上数，从 1 到 6。该爻阴阳互换，得到变卦。

### 3.2 大盘：时间起卦

问的是「这场交易」。时辰取美东时间里、包含开盘铃的那一个时辰。美股 9:30（美东）落在巳时。巳时的数是 6。卦在开盘前就算好，不等到 9:30。

```text
上卦 = mod8(年支 + 农历月 + 农历日)
下卦 = mod8(年支 + 农历月 + 农历日 + 时辰)
动爻 = mod6(年支 + 农历月 + 农历日 + 时辰)
```

年支、月、日、时辰都是 1 到 12 的整数，日是 1 到 30。用农历，不用节气月。年支取农历年，正月初一换年。立春起算的四柱年支不进起卦。闰月的月数与该月相同，不设 13。笔记写了正月到十二月，没有单列闰月；此处按通行梅花处理，若要改只改这一处。

现有 `dashboard/v1.html` 里还有上证。本引擎不用上证。美股会话卦用巳时。若以后要保留「开盘铃前另起一卦」，那是另一个命名问题，不替代会话卦。

时辰表（交易所当地钟点）：

| 时辰 | 数 | 当地时间 |
|---|---:|---|
| 子 | 1 | 23:00–00:59 |
| 丑 | 2 | 01:00–02:59 |
| 寅 | 3 | 03:00–04:59 |
| 卯 | 4 | 05:00–06:59 |
| 辰 | 5 | 07:00–08:59 |
| 巳 | 6 | 09:00–10:59 |
| 午 | 7 | 11:00–12:59 |
| 未 | 8 | 13:00–14:59 |
| 申 | 9 | 15:00–16:59 |
| 酉 | 10 | 17:00–18:59 |
| 戌 | 11 | 19:00–20:59 |
| 亥 | 12 | 21:00–22:59 |

钟点用美东时间，含夏令时。不用北京时间去套美股开盘。

目标日若不是美股交易日，改到下一场实际开盘的那天，农历也改到那天。周末和美股休市不占一个日卦。

同一时辰里，标普和纳指如果农历日相同，卦相同。这是时间卦的本意。回测分母只计标普。美股板块和个股不走这条，走 3.3。

### 3.3 板块与个股：开收盘报数

齐济 1999 用开盘、收盘的数字和把标的分开。笔记规定美股代号不走笔画，不走哈希。

预测下一场时，用已经走完的那场的开盘和收盘。预测下一周时，用这一周的开盘和这一周最后一场的收盘。指数不进入本节。

```text
S(p) = 印价十进制里的每一位数字相加。不预先收成固定小数位，不补零。

上卦 = mod8(S(开盘))
下卦 = mod8(S(收盘))
动爻 = mod6(S(开盘) + S(收盘))
```

`763.3` 与 `763.30` 的各位和都是 19。末尾的零不改卦。印价若带非零的第三位小数，例如 `763.301`，各位和变成 20，卦可以变。不先四舍五入。

例：收盘印价 `763.25`，`S = 7+6+3+2+5 = 23`，`mod8(23) = 7`，下卦为艮。

边界：

- 价格缺失、为零、或不是有限数：这场卦空着，档位为「缺价」。
- 只缺周开盘，或该周没有一场收盘：日卦仍可算，周卦空着。
- 高低价、成交量、前收、涨跌幅不进入 `S`。
- 数字和用绝对值的不复权印价。起卦锁死这个口径，日卦和周卦相同。收益用复权价，见 5.1，不进入 `S`。

### 3.4 一条已知的公式性质

时间卦的下卦和动爻共用「年支 + 月 + 日 + 时辰」这一个和。Joseph Yu 的模运算分析指出，因此一爻动的 384 种组合里，这套式子只落到其中一部分。报数法的下卦来自收盘、动爻来自开盘加收盘，约束不同。本设计保持笔记里的两套式子，不改式子去铺满 384 种。

## 4. 断卦层

### 4.1 体用

动爻在 1、2、3：下卦为用，上卦为体。动爻在 4、5、6：上卦为用，下卦为体。

五行：乾兑金，震巽木，坎水，离火，坤艮土。生：金生水，水生木，木生火，火生土，土生金。克：金克木，木克土，土克水，水克火，火克金。

| 条件 | 关系 | 总诀断语 |
|---|---|---|
| 体五行 = 用五行 | 体用比和 | 体用比和，顺 |
| 用所生 = 体 | 用生体 | 用生体，有进益 |
| 体所克 = 用 | 体克用 | 体克用，事情可成 |
| 体所生 = 用 | 体生用 | 体生用，有耗泄 |
| 用所克 = 体 | 用克体 | 用克体，事情不利 |

五行只有这五种关系，没有第六句。

### 4.2 旺衰

起卦仍用第 3.2 节的农历。旺衰看目标会话那天的节气月建，不是农历月，也不是取价那天。月建从该节气当天起，到下一节气的前一天止。变体 B 默认关闭，因此这里只改「体当令 / 体失令 / 体中」的标注，不改默认档位。

| 月建 | 起于 | 当令 | 失令 |
|---|---|---|---|
| 寅 | 立春 | 木 | 土 |
| 卯 | 惊蛰 | 木 | 土 |
| 辰 | 清明 | 土 | 水 |
| 巳 | 立夏 | 火 | 金 |
| 午 | 芒种 | 火 | 金 |
| 未 | 小暑 | 土 | 水 |
| 申 | 立秋 | 金 | 木 |
| 酉 | 白露 | 金 | 木 |
| 戌 | 寒露 | 土 | 水 |
| 亥 | 立冬 | 水 | 火 |
| 子 | 大雪 | 水 | 火 |
| 丑 | 小寒 | 土 | 水 |

体的五行等于当令，记「体当令」。等于失令，记「体失令」。其余记「体中」。旺衰写在断语旁边。默认档位不因旺衰改写断语。

总诀写「体宜旺，不宜衰」，但五句本身没有「失令则改判」。另有一条预注册变体，见 4.4，不作为默认输出。

### 4.3 起势和收势

动爻在用卦里，所以变爻只改用卦，体卦不变。

```text
起势 = 体 与 本卦之用 的关系
收势 = 体 与 变卦之用 的关系
```

总诀：用吉而变成凶，先吉后凶；用凶而变成吉，先凶后吉。这两句只写成这一场的前段和后段，例如「起势偏多，收势偏空」。主命中只用起势，对照这场开盘到收盘。收势只展示，不对随后几个交易日，也不拆成上午、下午各一档。

互卦由二三四爻、三四五爻组成，只标卦名，表示过程，不参加档位。

### 4.4 档位

已确认五档，与五句一一对应，不收成三档。引擎同时给出断语和档位，断语永远是上表五句。

| 关系 | 断语 | 档位 |
|---|---|---|
| 用生体 | 有进益 | 偏多 |
| 体克用 | 事情可成 | 略偏多 |
| 体用比和 | 顺 | 震荡 |
| 体生用 | 有耗泄 | 略偏空 |
| 用克体 | 事情不利 | 偏空 |

缺价时档位为「缺价」，不代入邻档。

比和的档位名仍是震荡。总诀的「顺」不是平。验收不把比和送进平桶。

已确认不把五档收成三档：略偏多不并入偏多，略偏空不并入偏空。主命中按五档分列，见 5.4。三桶只作旁边的粗表。

预注册变体 B，已确认默认关闭：体失令，且关系为用生体或体克用时，档位向震荡挪一档（偏多变为略偏多，略偏多变为震荡）。体当令且关系为体生用或用克体时，同样向震荡挪一档。不变断语，不把偏多改成偏空。这条变体单独记分，不并进默认命中率。默认输出不使用这条挪档。

## 5. 回测层

回测检验的是冻住的档位对不对得上事先写好的收益桶。不搜索新规则，不按命中率改五句。

### 5.1 样本

标的清单在开跑前固定，只用美股。时间卦的回测分母只留标普：纳指与标普同一农历日、同一巳时，卦相同，不重复进入分母。板块 ETF 和个股用开收盘数字和，各自进入分母。`sectors.json` 里的 A 股代码不进入。中途不增补后来才上市、事后看涨得好的名字。停牌日、无成交日进入「缺价」，不删掉再算命中率。

起卦锁死用不复权印价。收益用复权价。除权日另列一张清单。只覆盖美股。

### 5.2 信号与结果

日尺度：板块与个股在场次 T 的不复权收盘印出之后，用 T 的不复权开盘和收盘做数字和，起势档位指向场次 T+1。指数不走数字和。时间卦用 T+1 的农历和巳时，在 T+1 开盘前冻住。分母里的指数只计标普。主命中只用起势。

主结果是 T+1 的开盘到收盘，用复权价：

```text
r = 复权收盘(T+1) / 复权开盘(T+1) - 1
```

这场会话的起势对这场会话的价格路径。另记一条辅结果，不与主结果混成一个命中率：

```text
r_cc = 复权收盘(T+1) / 复权收盘(T) - 1
```

除权日另列，不改这两条公式。

周尺度：板块与个股在该周最后一场收盘后起卦，用该周不复权开盘和该周最后一场的不复权收盘。结果是下一周的周开盘到周收盘，收益用复权价。指数没有周数字和。

### 5.3 平盘带和费用

费用不从命中率里扣除。费用用来事先规定「平」的宽度。宽度写死后不再按结果改。

```text
band = max(0.20%, 该市场一回合费用)
上涨桶：r > band
下跌桶：r < -band
平桶：其余
```

0.20% 沿用此前月度对照里的平盘定义，并与费用取较宽者。美股一回合按双边佣金加一个固定价差估算。费率表附在回测记录里。个股不单独拟合 band。

费用出现的第二个地方是一条说明性损益，不作为验收：偏多与略偏多做多，略偏空与偏空做空，下一场开盘进、收盘出，扣一回合费用。比和不放进这条曲线。这条曲线回答「若把档位当成仓位会怎样」，不回答「卦准不准」。

### 5.4 命中

主命中按五档分别报告：偏多、略偏多、震荡、略偏空、偏空。五档不合并。记入主命中的是起势档位，对照这场复权开盘到收盘。收势不进主命中。缺价不记入分母。

比和的档位名仍是震荡。总诀的「顺」不是平。主命中不把比和送进平桶，也不把比和并进上涨侧或下跌侧。比和这一档只报告样本数和收益分布，不设平桶命中率。

其余四档各自对照价格方向，分开计：

| 档位 | 主命中对照 |
|---|---|
| 偏多 | 上涨：r > band |
| 略偏多 | 上涨：r > band |
| 震荡（比和） | 不设平桶命中，只报告分布 |
| 略偏空 | 下跌：r < −band |
| 偏空 | 下跌：r < −band |
| 缺价 | 不记入分母 |

同时报告「始终记上涨侧」的命中率，作为基线。变体 B 单独一张表，不并进默认主命中。

旁边附一张三桶粗表，不作为验收。上涨侧只收偏多与略偏多，下跌侧只收略偏空与偏空。比和不进入这张粗表的平桶。

样本外按时间切，不随机抽天。规则来自笔记，不在前半段里挑参数。仍把分数拆开报：例如 2016–2020 与 2021–2025 各一张，后一段不参与任何口径选择。band 若调整，只许在前一段定，后一段原样使用。

不报告盘中命中。主命中不把起势、收势分开对上午、下午。收势只展示。

| 页面 | 现在的起卦 | 现在的着色 | 本设计 |

## 8. 验收时看什么

- 同一组农历和同一组开收盘，两页得到同一个关系、同一句断语。
- 缺价不显示邻档。
- 回测主表按五档分列起势命中：样本区间、band、各档样本数。比和不设平桶命中。三桶粗表不作为验收。始终上涨侧的命中率另报。变体 B 不混进这张主表。除权日另列。
- 指数只走时间卦，分母只计标普。板块与个股的数字和用印价全位，周收盘用该周最后一场。年支正月初一换年。
- 断语五句与总诀用词一致，不出现「动为体」。
